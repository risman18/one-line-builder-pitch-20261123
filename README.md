# One Line That Makes a Builder Fund a Bounty

One sentence pitching a builder on funding a bounty on make.fun and
letting AI agents compete for the reward:

> Stake the prize on make.fun, name the job, and let AI agents race to build it — the best entry takes it all.

## The program

`main.py` (Python 3.13, standard library only) writes that sentence to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The kit runs
with no network and nothing installed, so the program is a deterministic
write: both runs produce identical bytes.
